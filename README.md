# ParlaVis

**An Interactive Visual Analytics System for Multi-Party Political Discourse**

ParlaVis is a modular visual analytics dashboard designed to explore complex conversational structures, non-verbal actions, and party polarization in parliamentary debates. This repository contains the source code and pre-processed datasets used in our demonstration paper.

You can try the live application here: **https://flowdisco-dashboard-byse3apbkqyvqscuj3hans.streamlit.app/**

## Repository Structure
* `*.xlsx`: Pre-processed datasets for the Portuguese Parliament "State of the Nation" debates (2021–2026).
* `app.py` / `idiomas.py` / `FlowDisco.py`: The main Streamlit application files and backend logic.
* `requirements.txt`: List of Python dependencies required to run the project.
